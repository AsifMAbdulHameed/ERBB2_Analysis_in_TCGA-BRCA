# ERBB2 Analysis in TCGA-BRCA

Final project for Foundations of Data Science, Dartmouth College.

## Project Overview

This project explores ERBB2 gene expression in the TCGA Breast Invasive Carcinoma (TCGA-BRCA) cohort using RNA-seq count data and corresponding clinical and molecular metadata.

The analysis focuses on the distribution of ERBB2 expression, its relationship with CDK4 expression, differences in ERBB2 expression across PAM50 molecular subtypes, and expression patterns across a panel of breast cancer-related genes.

## Repository Contents

- R Markdown source code for data analysis and visualization
- Knitted R Markdown PDF
- LaTeX source for the final report
- Compiled final report PDF
- Figures generated for the final report

## Data

RNA-seq count data and corresponding clinical and molecular metadata were obtained from the TCGA Breast Invasive Carcinoma (TCGA-BRCA) project through the National Cancer Institute Genomic Data Commons.

The data files are not included in this repository.
